## 📌 Overview

This repository contains **Natural Language Processing (NLP) practical codes and notebook implementations** aligned with the **SPPU curriculum**. It focuses on text preprocessing, language modeling, sentiment analysis, syntactic parsing, and transformer-based models.

### Key Focus Areas

| Area | Topics |
|------|--------|
| **Text Preprocessing** | Tokenization, Stemming, Lemmatization, Stop-word removal |
| **Vectorization** | Bag of Words (BoW), TF-IDF, Word2Vec embeddings |
| **Sequence Models & Classification** | Text Classification, Sentiment Analysis, Naive Bayes |
| **Advanced NLP** | Named Entity Recognition (NER), POS Tagging, Transformers |
