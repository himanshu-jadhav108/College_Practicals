## 📌 Overview

This repository contains **Internet of Things (IoT) practical codes, setup guides, and simulation scripts** aligned with the **SPPU curriculum**. It includes hands-on implementations covering sensor interfacing, microcontrollers, embedded Python programming, and cloud telemetry integration.

### Key Focus Areas

| Area | Topics |
|------|--------|
| **Sensor Interfacing** | Temperature, Humidity, Ultrasonic distance, Motion sensors |
| **Microcontrollers** | Arduino, ESP8266 / ESP32, Raspberry Pi GPIO |
| **Protocols & Communication** | MQTT, HTTP APIs, Serial/I2C/SPI |
| **IoT Cloud & Telemetry** | ThingSpeak, Adafruit IO, Local Dashboards |

## 🚀 Getting Started

1. **Navigate to the IoT folder**:
```bash
cd Internet_Of_Things
```

2. **Install dependencies**:
```bash
pip install -r requirements.txt
```

---

## 🛠️ Tech Stack & Requirements

- **Languages & Frameworks:** Python 3.x, C/C++ (Arduino IDE)
- **Libraries:** `paho-mqtt`, `pyserial`, `requests`, `RPi.GPIO` (Raspberry Pi environment)
- **Platforms:** Arduino IDE, Thonny, ThingSpeak / Adafruit IO
